# Generate AIS Units API

## Overview
Streaming endpoint to generate AIS (Action-Impact-Situation) units from raw experience descriptions using AI.

## Endpoint

### POST /experiences/generate-ais (SSE Stream)
Server-Sent Events endpoint that streams AIS units as they are generated by the LLM.

**Request Body:**
```json
{
  "rawExperienceDescription": "Worked as a senior developer at XYZ Corp. Led a team of 5 developers to build a new microservices architecture using Node.js and Docker. Reduced deployment time by 60% and improved system reliability."
}
```

**Response (SSE Stream):**
Each event contains a single AIS unit as it's generated:
```
data: {"action":"Led a cross-functional team of 5 developers to design and implement a microservices architecture","impact":"Successfully transitioned monolithic application to 12 independent microservices","context":"Senior developer role at XYZ Corp, working with distributed systems","skills":["Leadership","Microservices Architecture","Node.js","System Design","Team Management"]}

data: {"action":"Engineered and implemented CI/CD pipeline automation using Docker and Jenkins","impact":"Reduced deployment time from 2 hours to 15 minutes (87.5% improvement)","context":"DevOps transformation initiative with focus on continuous delivery","skills":["Docker","Jenkins","CI/CD","DevOps","Automation"]}
```

The stream completes when all AIS units have been generated.

### How It Works

1. **User submits raw experience description**
   - Can be informal, unstructured text
   - The AI will enrich and structure the content

2. **LLM Processing (GPT-4o-mini)**
   - Analyzes the description
   - Identifies distinct achievements/responsibilities
   - Structures each into AIS format:
     - **Action**: Specific task performed (with action verbs)
     - **Impact**: Measurable results (with metrics when possible)
     - **Context**: Situation/environment
     - **Skills**: Technical and soft skills demonstrated

3. **Response**
   - Returns 3-8 structured AIS units
   - Each unit is complete and ready to use
   - Skills are categorized and extracted

### Benefits

- **Time-saving**: Automatically structures experiences
- **Quality**: AI enriches descriptions with industry-standard terminology
- **Consistency**: All units follow the same format
- **Skills extraction**: Automatically identifies relevant skills
- **Metrics inference**: Adds reasonable metrics when appropriate

### Usage Examples

**Example 1: Vague Description**
```
Input: "Developer at tech company. Made things faster."

Output: Multiple detailed AIS units with:
- Specific actions (e.g., "Optimized database queries...")
- Quantified impacts (e.g., "improved response time by 40%")
- Clear context (e.g., "backend optimization initiative")
- Relevant skills (e.g., ["SQL", "Performance Optimization", "Database Design"])
```

**Example 2: Detailed Description**
```
Input: "As a Senior Full Stack Developer at TechCorp from 2020-2023, 
I led the development of a React-based dashboard that served 50K users. 
Integrated with 5 different APIs and reduced page load time from 8s to 2s."

Output: Multiple AIS units breaking down:
- Frontend development achievements
- API integration work
- Performance optimization results
- Technical leadership aspects
```

## Testing

To test the streaming endpoint:

```bash
# Using curl to consume SSE stream (POST with body)
curl -N -X POST http://localhost:3000/experiences/generate-ais \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "rawExperienceDescription": "Your experience description here"
  }'
```

```javascript
// JavaScript/TypeScript client example
// Note: EventSource doesn't support POST, so use fetch with ReadableStream
async function streamAisUnits(description) {
  const response = await fetch('/experiences/generate-ais', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json',
      'Accept': 'text/event-stream'
    },
    body: JSON.stringify({
      rawExperienceDescription: description
    })
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = line.slice(6);
        const aisUnit = JSON.parse(data);
        console.log('Received AIS unit:', aisUnit);
        // Process each AIS unit as it arrives
      }
    }
  }
}
```

## Notes

- Requires valid JWT authentication
- Uses OpenAI API (requires OPENAI_API_KEY in environment)
- Temperature set to 0.3 for consistent, focused responses
- Streams results in real-time as they are generated
- Client must support Server-Sent Events (SSE)
- Stream automatically closes when generation is complete
